# Boardman

**A premium, cinematic snooker experience.**

Boardman is a snooker-focused web experience. The current milestone is a static landing page built with HTML, CSS and JavaScript, prepared for deployment to Cloudflare Pages.

## Current scope

- Static, responsive landing-page experience.
- Cinematic snooker visual direction.
- Optimized static hero image at `media/boardman-hero.webp`.
- No background video in the current milestone.

## Run locally

Because this milestone is a static website, you can open the page in a browser or serve the repository root with a local static web server.

## Deploy to Cloudflare Pages

- Framework preset: **None**.
- Build command: leave empty.
- Build output directory: repository root (`/`).
- Root directory: leave blank.

No build step or environment variables are required for the documented static landing-page milestone.

## Product scope and safety

This milestone is presentation-only. Virtual credits are an in-game concept. Real-money wagering, deposits, withdrawals, payments and payouts are not implemented. The join form is a demo and does not save or transmit email addresses. Leaderboard entries are illustrative sample data.

Do not describe demo functionality as a live-money or production transaction feature.

## Development notes

Keep the experience lightweight and accessible. Optimize images, preserve mobile responsiveness and update this README whenever deployment requirements or implemented functionality change.
