# Boardman

Premium cinematic snooker landing page. Built with React, TypeScript and Vite.

## Development

```bash
npm install
npm run dev
```

## Cloudflare Pages

Connect this repository to Cloudflare Pages. Build command: `npm run build`. Build output directory: `dist`.

The hero video is an optional local asset at `public/media/boardman-hero.mp4`. Until that licensed video is added, the designed poster fallback is shown. This first milestone uses virtual credits only; no real-money wagering, deposits, withdrawals, or payouts are implemented.
